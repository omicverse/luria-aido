# Luria-AIDO v2 架构设计

三部分：编码器选型（开源权重）、世界模型核心、训练数据。

---

# 零、发布形态：多模态整合，整合层是发布物

目标是**开源 luria-aido**。每个模态都已经有做到 SOTA 的开源模型
（蛋白、DNA、RNA、结构、单细胞、化学），把它们整合成一个多模态世界模型——
这就是 AIDO Cell 在做的事，也是我们要做的事。

## "整合"和"缝合"的差别落在结构上

```
缝合   每个模态各自预测，最后拼一个 API
整合   所有读出从同一个共享状态 z' 解码，且这个约束可证伪
```

区分二者的实验在第二节：**shuffle gap** 和**共享/残差两阶段分解**。
没有这两条，"多模态世界模型"只是一个 import 后面的几个预测器。

## 发布物 = 整合层的权重

```
proj_m     各模态冻结特征 → 统一锚空间        ← 训练、发布
E_cell     表达谱 + 锚集合 → 细胞态 z          ← 训练、发布
T          转移算子：交叉注意力 + 门控          ← 训练、发布
D_m        每模态解码器，全部读同一个 z'       ← 训练、发布
gene_embed 基因身份嵌入表                      ← 训练、发布

模态编码器（ESM2 / GENERanno / MoLFormer / STATE SE / GB.RNA …）
           ← 冻结，声明为依赖，不重分发
```

**不重分发是标准做法**——一个加载 ESM2 的包不会把 ESM2 塞进自己的 wheel。
用户从原始来源按原始许可获取。这同时解决了许可问题：我们**使用**不重分发。

**这一层才是"世界模型"所在的位置。**模态编码器是感官，
共享状态和它的转移是模型本身——也是判据①（改一族不退化另两族）
唯一可能成立的地方。

## 方法贡献（不能只是"我们也整合了一个"）

v1 实测出的三件事本身就是论文：

1. **扰动模型可以在指标上很好看，同时完全无视扰动。**
   shuffle 对照：打乱 cond→target 对应后验证损失纹丝不动（0.017 / 0.002，噪声内）。
   而此前 27 轮的表示排序、融合结构、容量消融**全在这个底座上比噪声**。
   这个失败模式在文献里不是标准检查项。
2. **共享成分主导了这个领域的指标**：L1000 上 train-mean 解释 98.5% 方差。
3. **修法**：`shuffle gap` 提升为一等指标 + 两处残差分解（第一节末、第二节）。
   可迁移，不只对我们的模型成立。

论文形态：**发现 + 方法 + 一个整合式多模态开源世界模型**。
**跑不赢 STATE 不影响成立**——判据是判据①和 shuffle gap，不是排行榜名次。

# 一、编码器栈 —— 各模态取 SOTA，冻结，整合层才是我们训的

## 论点

每个模态都已经有做到 SOTA 的开源模型。**没有理由用 6000 条序列自己重训一个更差的。**
把它们整合成一个多模态世界模型，整合层是我们的贡献。

## 先纠正一个 v1 遗留的错误推论

v1 的 perceiver 消融（16/2 → 64/2 → 16/4，v2 0.86 → 0.96 → 1.05）
**是在 shuffle gap = 0 的状态下测的**——模型根本没在用条件信息。
那个 regime 下加容量只能过拟合，不可能帮上忙。

**所以那三个点对"容量够不够"是无信息的。**不能拿它推出"小模型就够"。
容量问题要在 gap > 0 之后**重新问一遍**，不是已经答完了。

同理，`不训练的 cosine-kNN（蛋白特征）0.6431 > 六个训练模型（全部 < train-mean 0.6183）`
这条实测，读法是：**冻结特征里有信号，是训练把它丢掉了**。
它支持"用各模态最好的编码器"，并且指认问题在整合/训练策略——不是编码器不够好。

## 选型：每个模态取**小尺寸变体**，冻结

**全部用能在小机器上跑的版本，不用全量版。**理由有三条，第三条最重要：

1. **发布物要能被别人跑起来。**依赖一个 16B 的编码器，等于没发布
2. **消融才做得起。**小编码器的嵌入几分钟算完，可以对每个消融重算整套特征
3. **编码器尺寸本身变成一个可测量的轴**——见下面的扫描

| 模态 | 选用（小） | 参数 | 全量版（只作对照上界） |
|---|---|---|---|
| 蛋白序列 | `esm2_t12_35M` / `esm2_t30_150M` | 35M / 150M | ESM2-650M（本地已有）、ESM-C |
| DNA 调控 | HyenaDNA-tiny / Caduceus / NT-50M | 1.6M–50M | GENERanno-0.5b（本地已有）、GB.DNA-7B |
| 单细胞态 | **`GB.Cell-3M` / `GB.Cell-10M`** | 3.6M / 10M | STATE SE-600M、GB.Cell-100M |
| 化学 | **ECFP4 + RDKit 描述符（0 参数）** / ChemBERTa-77M | 0 / 44M | MoLFormer-XL 177M（本地已有） |
| 结构 token | `GB.StructureEncoder` | 5.87M | — （本来就小） |
| RNA / 异构体 | RNA-FM / RiNALMo 类小模型 | ~100M | GB.RNA-1.6B |
| 蛋白结构 | — | — | Boltz-2 / Protenix v2 **运行时委托，不进 checkpoint** |

**冻结特征总量降到 ~100M 量级**，整套嵌入几分钟算完、一次复用。

### 化学腿直接从 ECFP4 起

v1 实测：`ECFP 0.74 / MoLFormer 0.79 / ChemBERTa 1.29`——**最便宜的那个最好**。
ECFP4 是算法、零参数、零许可，先用它。神经分子编码器作为可选增强。

### 编码器尺寸做成一个扫描轴，不是一个假设

每个模态跑 `{小, 中, 全量}` 三档，在 **gap > 0 的条件下**看下游指标怎么动。

这回答两件事：**大编码器到底值多少**，以及
**"不训练的 kNN 0.6431 赢过所有训练模型"是不是意味着小编码器就够**。

如果小档和全量档差距很小，那本身是一个值得报的结果——
而且它让发布物可以理直气壮地只依赖小模型。

**注意 v1 的教训**：这个扫描必须在 gap > 0 之后做。
gap = 0 时所有档位都会给出一样的数（因为条件信息根本没被用），
那正是 v1 perceiver 消融为什么无信息。

## 整合层（这才是发布的权重）

```
每个模态 m:  h_m = frozen_encoder_m(input_m)     离线算好
             a_m = proj_m(h_m)                   → 统一锚空间 d_a    ← 训练
z            = E_cell(x, {a_m})                  细胞态              ← 训练
z'           = T(z, u)                           转移，交叉注意力+门控 ← 训练
y_m          = D_m(z')                           每模态解码，共享 z'  ← 训练
```

**容量不预设。**先按 100–300M 可训练参数起，然后在 gap > 0 的条件下做容量扫描——
这是 v1 欠下的那个实验，要在正确的 regime 里补做。

## 整合层必须"只能加不能减"

这是针对 kNN 那条实测的直接设计：**训练不许把冻结特征里已有的信号弄丢**。

```
y = g(a_m 直接线性/kNN 探针)  +  Δ(z', u)
    └─ 先拟合、然后冻结 ─┘      └─ 只训这个 ─┘
```

`g` 是特征的线性探针（或 kNN），先单独拟合、冻结；`Δ` 只学它之上的残差。
**`Δ = 0` 时性能恰好等于"直接用冻结特征"（0.6431 那个数）**，
训练只能往上加。这样"训练把信息弄丢"在结构上不可能发生。

和第二节的共享/残差分解是同一个手法，作用在两个不同的地方：
- 第二节：把**目标的共享成分**拿掉，逼模型用 `u`
- 这里：把**特征已有的信号**保底，防止训练丢信息

两条都是针对 v1 实测出来的具体失败，不是通用正则。

## 三个整合难点（要在设计里回答，不能绕）

1. **粒度不同**：蛋白/DNA 锚是**逐基因**的（6000 个），细胞态是**逐细胞**的，
   化学是**逐分子**的。`E_cell` 要能把逐基因的锚集合池化进逐细胞的状态。
2. **缺模态**：不是每个基因都有结构、不是每个药都有 SMILES。
   缺失要走可学习的 mask token，不能填零（填零会被当成一个特定的值）。
3. **尺度不同**：各编码器输出的范数差几个数量级。
   `proj_m` 前必须按模态标准化，且**标准化统计量只从训练集算**。

## 许可

**luria-aido 是学术研究，不商业化**——许可不是约束。
各模态编码器按各自的学术/非商业条款使用即可，**STATE 默认开启**。
发布时不重分发第三方权重（声明为依赖），这只是打包惯例，不影响选型。

# 二、世界模型核心

## v1 为什么不成立（这是设计的出发点，不是评价）

v1 实测的 shuffle 对照：**把 cond→target 的对应完全打乱，v1/v2 纹丝不动
（0.017 / 0.002，噪声内）**。条件信息对输出零影响。

原因不在融合结构（perceiver 试了三个规模点，都更差），在两件事：

1. **目标的共享成分吃掉了一切。**L1000 上 train-mean 解释 98.5% 方差。
   模型只要输出那个共享方向就能拿到几乎全部的分数，`u` 是多余的。
2. **状态是常量。**`z0` 不随细胞变，扰动是 `z0 + W·u` 的线性位移，
   位移方向全部塌到同一个应激方向上。

## 新结构

```
z   = E_cell(x)                    细胞态，GB.Cell 编码真实表达谱
u   = 扰动 token 序列
      KO(g)        → anchor(g) ⊕ type[KO]
      KD(g, eff)   → anchor(g) ⊕ type[KD] ⊕ eff
      OE(g, level) → anchor(g) ⊕ type[OE] ⊕ level
      drug(s, dose)→ chem(s)   ⊕ type[DRUG] ⊕ log dose
      anchor(g) = DNA(g) ⊕ protein(g)          ← 三条腿的桥

z'  = T(z, u)                      转移算子：z 作 query，u 作 key/value 的交叉注意力 + 门控
y_m = D_m(z')                      每个模态一个解码器，全部从同一个 z' 解码
```

**关键约束，两条，都是为了让 `u` 不可省略：**

### ① 结构上把共享方向拿掉

```
y = ŷ_shared(z)  +  Δ(z, u)
```

`ŷ_shared` 先单独训练（**不看 u**），然后**冻结**。`Δ` 只在残差上训练。
这样 `Δ` 要么用 `u`，要么输出零——**没有"靠共享方向蒙混"这个选项**。
而且 `Δ` 上的指标是干净的：它的零假设就是 0。

v1 的 `mean_prior` 做了一半（decoder bias 初始化成 train-mean），
但 `Δ` 和 `ŷ_shared` 仍在同一组参数里联合训练，共享方向可以被重新吸收进去。
**这里要求它们是两个阶段、两组参数。**

### ② 把 shuffle 提升为一等指标

每次评估都算两遍：真实 `u` 和打乱的 `u`。主指标是

```
gap = L_Δ(shuffled u) − L_Δ(true u)
```

**"条件信息到底起多少作用"，连续测量，而不是训练完做一次对照才发现是零。**
v1 是在第 28 轮才做那个 shuffle 对照的——那之前的表示排序、融合结构、
容量消融全部是在 gap=0 的底座上比噪声。

### ③ 世界模型的共享性要结构上成立，不能只靠声明

- 所有解码器读同一个 `z'`，不允许任何一族有私有的状态分支
- 每步训练的 batch 里所有族都在，不做族级课程切换
- **判据①在收敛态上判，不是每步护栏**（2026-08-30 修订，见第五节）：把多个
  各自 SOTA 的单模态模型压进一个共享 `z`，每个模态的表示都要被投影/压缩——
  **不退化就说明没真的融合**。每步设"任一族退化就拒绝"的护栏会禁止融合必需的
  过渡期，把模型永远锁在"三个独立预测器"的局部最优里。正确的检查是：训练要
  足够长、记录每族指标随 epoch 的完整轨迹，看形状是"谷形（先降后升）"还是
  "单调下降到底"——前者是融合的过渡，后者才是互相干扰。

## 「改一个模态，能不能知道其他模态的变化」

这是这个模型最该回答的问题，也是 AIDO 的 C1（读出互相自洽）+ C2（干预跨尺度传播）。
**分三层，能力完全不同，不能互相冒充。**

| 层 | 问题 | 当前设计 | 判据 |
|---|---|---|---|
| ① | 施加扰动 `u` → 所有读出协同变化 | **结构上保证**（全部从同一 `z'` 解码） | 扰动后各读出都动，且 shuffle gap > 0 |
| ② | 观测模态 A → 推断模态 B | **做不到，要加训练目标** | 留出模态重建：训练时没一起见过的模态对能否互推 |
| ③ | **干预**模态 A → B 的因果变化 | 只在有干预数据处成立 | 需要该模态对的干预数据 |

### ② 需要加的：随机模态遮蔽

```
训练目标   随机遮蔽模态子集 M，用剩下的编码出 z，解码回全部模态
           （现在只有"扰动 u 写入"一条路，没有"把模态设成某值"这条路）

推理用法   z* = argmin_z ‖D_A(z) − a_target‖ + prior(z)     把 A 设成目标值反解 z
           y_B = D_B(z*)                                     其他模态从同一 z 读出
           或用摊销编码器：z* = E_cell(x 中 A 被替换后的版本)
```

这同时是 **C1 的真正测试**——比"两两一对碰巧不矛盾"强得多，
因为它要求任意子集都能互相还原。

### ③ 的陷阱：锚是标签嵌入，不是机制

现在的 DNA / 蛋白锚是"**基因 g 的表示**"。所谓"改 DNA"实际上只是换了个基因名，
不是编辑了序列——**那样的 A→B 不是机制传播，是查表**。

**但有一条腿的输入是真正可编辑的：F3。**它吃的就是调控序列本身，
而且是三族里唯一大幅跑赢零假设的（corr 0.715 vs shuffle 地板 1.0016±0.0119）。

```
现在就成立   编辑启动子序列 → 调控活性变化            F3 已验证
待打通       调控活性 → 细胞态 z → 表达 / 通路        ← 这就是 C2
             把 F3 的输出接进 z，是本项目最有价值的一步
已成立       KO / 药物 → 表达                        Perturb-seq 本身是干预数据
```

**其余模态对在拿到对应干预数据之前只能标 ②，不能标 ③。**
API 的 `provenance` 里要带这个层级标记：`level: 1 | 2 | 3`。

### 一条容易被忽略的前提

**模型能学到的耦合，上限是数据里的耦合。**如果两个模态在数据里从未在同一个细胞上
一起被观测过，模型学到的"关系"只能来自基因身份这个共同索引——
那是查表不是耦合。**所以配对数据的覆盖情况要先量出来、写进报告**：
哪些模态对有真配对、哪些只有基因身份连着。

**方向相反。**合并前要确认标签语义，不能直接拼。

## 数据不是万能的（v1 已经证伪过一次）

我在 v1 里推荐过 L1000 扩数据，结果全部配置更差——因为 L1000 的共享成分 98.5%，
加数据只是加了更多同一个方向的点。**所以①的残差结构必须先做，再加数据。**
否则新数据会重复同一个失败。

# 四、落地顺序

```
1  自建 E_cell（可训练，逐细胞），输入含 STATE SE-600M 的离线嵌入，把 z 从常量换成状态
   立即测 shuffle gap —— 这是唯一有意义的第一个数
2  实现 ŷ_shared 冻结 + Δ 两阶段训练
   再测 shuffle gap。若仍 ≈0，问题不在数据，继续查结构
3  gap > 0 之后才补 Replogle（先做标签语义对齐）
4  三族联合训练 + 退化护栏，验判据①（改一族不退化另两族）
5  记分牌 / 图谱 / 设计回路
```

**第 1、2 步各自的判据都是 shuffle gap**，不是任何一个 loss 数值。
gap 是零就没有世界模型，其余指标都是在量共享方向。

# 五、实测记录与设计修订（2026-08-29，v2 round 2–4 后）

本节跟着测量走，不改判据。三条设计约束里两条被证伪，一条成立；一条架构假设（逐细胞 z）不被支持。所有数字来自账本 camp_9d2905a64d7c445b9504e1a7aaf118b0。

## 约束①（共享/残差两阶段：ŷ_shared 先训后冻结 + Δ）—— 证伪

| 变体 | gap_min | 备注 |
|---|---|---|
| joint（朴素，无两阶段） | 3.76 | 参照 |
| two_stage_yes（stage-1 冻结 T） | 1.73 | F1 预测退化成常量（置换 null_sd 1e-4） |
| two_stage_fixed（stage-1 训 T、只冻读出） | 1.19 | 修正死锁后仍塌缩，F2 也从 4.1 掉到 1.2 |
| two_stage_percell | 3.30 | **把 F3 gap_z 从 60 打到 17.8** —— 正是判据①禁止的改一族退化另一族 |

结论：Δ 分支在 F1/F2 上都不如朴素 joint；"先训后冻"结构把条件通路堵死。**Δ 的正确形态是零初始化残差头全程联合训练，不是两阶段。**

## 约束③（特征保底探针：y = g(冻结特征) + Δ，g 先拟合后冻结）—— 证伪

`probe_frozen` gap_min 0.57、F1 gap 0.57 —— **比训练侧打乱 cond→target 的对照（0.68）还低**。
先拟合再冻结 g 把 Δ 的路堵死：冻结的线性探针抢走全部输出容量，Δ 无残差可学。

## 先退化再进化：为什么"退化护栏"是错的（2026-08-30 修订）

v1 的教训"六次训练让 F3 从 0.284 退化到 0.33"在 v1 的语境里是真的——但那是
**没有共享的退化**（三族各训各的，F3 掉下去没有回报）。在真正的共享模型里，
"每族相对上一个 checkpoint 退化就拒绝该步"会禁止融合必需的过渡期：

> 把多个各自 SOTA 的单模态模型压进一个共享 z，每个模态的表示都要被投影/压缩。
> **不退化就说明没真的融合**——各干各的当然谁都不掉。退化是融合的入场费。

### 实测：state_percell_long（1200 epoch）—— 第三种形状：纯过拟合

2026-08-30 拉长 state_percell 到 1200 epoch（无每步护栏、逐族轨迹）：
三族 loss 全部"先降（好）后升（坏）"——v1 2.48→1.10@ep105→1.68、
v2 0.60→0.54@ep57→0.75、v3 1.23→0.83@ep181→1.19。训练 loss 降 5 倍
（2.75→0.52），验证指标从 ~ep10 起平掉或变差。**既不是谷形也不是单调下降，
是纯过拟合**：模型从没进入融合动力学，800 个 epoch 全花在记忆上。
best checkpoint（总 val 最小，早期）gap_min 2.97，略低于 120 epoch 的 3.55。

**"掐在谷底"的假设被反驳**——percell 长训没有出现"先退化再进化"。

### 为什么过拟合：监督粒度错了（2026-08-30 用户诊断，本轮最重要）

```
        训练样本    目标维度    形式
F1        137        5054      D_expr(z) → 5054 维一次输出   ← 137 个样本
F2        664        2000      同上（166 个唯一药物）
F3     402,296        —        RegulatoryHead(z, toks)       ← token 级
```

**F1 只有 137 个训练条件，要学 5054 维响应，参数百万级——必然过拟合。**
X-Pert 的做法（`xpert/models/cell_encoder.py` 的 GeneEncoder + ExprDecoder +
`xpert/loss/loss.py` 的 masked_mse_loss）：每个基因一个 token 嵌入，解码器
作用在 token 上输出每基因一个标量，**参数经基因嵌入表跨基因共享**。
监督粒度逐基因：137 × 5054 基因对 ≈ 69 万监督点（我们 137 个样本，
有效样本量差 5000 倍）。

**反证在我们自己代码里**：`RegulatoryHead(z, toks)` 本来就是 token 级的，
而 F3 是三族里唯一真跑赢零假设的（corr 0.715 vs shuffle 地板 1.0016）。

### 修法：F1/F2 解码器改 token 级（2026-08-30 实施中）

```
现在   D_expr(z) -> R^{5054}
改成   D_expr(z, gene_token) -> R      对每个基因，参数共享
       gene_token = 可学 gene 嵌入 ⊕ 现有的 DNA/蛋白锚
损失   逐基因 masked MSE，在 (条件 × 基因) 上平均（现状就是）
```

`RegulatoryHead` 的写法直接借鉴。实现：`world_v2.TokenExprDecoder`，
y(g,z) = out(GELU(w_z(z) + w_t(token_g)))，token 表 = bridge(anchor) ⊕
可学习 gene_token_embed（bridge 输出初始化，保证 held-out 基因有合理初值）。
**零数据成本、零下载，改完立刻重测 gap。先只改这一处**，其它配置保持
joint_f3init_z0detach（当前最好）一致，才能归因。只有 token 级仍不行才补
Replogle 2022（CRISPRi，注意与 Norman CRISPRa 方向相反，合并前对齐标签）。

### 实测：token 级未提升，Replogle 数据是答案（2026-08-30 晚）

- **token 级解码器**（3 seeds 120ep：0.06/2.63/4.25；2 seeds 480ep：0.06/3.11）：
  参数共享本身不提升条件结构——loss 层面本就是逐基因 masked MSE（137×5054 监督点），
  真正变的是参数共享，而共享无增益。s2 持续塌缩（种子问题，非收敛问题）。
- **Replogle 2022 K562 CRISPRi**（`data_replogle/`，1971 扰动，836 个有 anchor 的
  train 条件 vs Norman 137）作 F1 数据源：**首个 3-seed 口径稳定超过 v1 基线的配置**——
  gap_min 4.03/3.64/4.22（均值 3.96±0.30 vs v1 3.67±0.81），每个 seed 都 >3.6。
  F1 条件结构大幅提升：gap 6.8–8.5（Norman z0detach 2.5–5.9）、F1 MSE 0.921–0.923
  大幅低于 train-mean 0.971（Norman 下只是勉强过）。
- **干净对照**：同一结构（joint_f3init_z0detach）、只换 F1 数据源。
  **结论：F1 条件结构的关键是训练条件数（137→836），不是解码器结构。**
